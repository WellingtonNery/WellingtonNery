### 100 Days of Shogun
A 2D decision-based game inspired by *Reigns*. You play a shogun, and every choice shifts three interconnected variables (Satisfaction, Population and Money) over 100 days. Team project for the Algorithmic Reasoning course at PUCPR.

**My part:** the game's logic structure, the audio system, the images and the prestige system, plus the technical documentation (README).

**Technologies:** Python, Pygame  
🔗 [GitHub repository](https://github.com/WellingtonNery/100daysShogun)

---

### Bola na Rede
A goal detection system built on a small PVC soccer goal. Infrared beams wired to an ESP32 tell the ball apart from a person by how long each beam stays cut, a DFPlayer Mini plays a sound on every goal, and a live scoreboard runs on a web page served by the ESP32 itself. In the final tests it counted 20 of 21 kicks (95%). Team project for the Cyber-Physical Systems Connectivity course at PUCPR.

**My part:** sensor wiring and assembly across two protoboards, and running the test rounds used to calibrate the detection logic.

**Technologies:** ESP32, C++ (Arduino), IR sensors, HC-SR04, DFPlayer Mini  
🔗 [GitHub repository](https://github.com/JvVicente/BolaNaRede)

---

### PUC-Imprest
A team project (team OWNERS) to unify the loan process for electronic devices at PUCPR, like notebooks and ESP32 boards. In its second stage, the front end runs on a PHP backend with a MySQL database, with CRUDs for users, rooms, equipment, incidents and permissions. I built the Users CRUD (students, professors and technical staff in a single flow, with hashed passwords) and wrote the "Register return" use case. Still under development.

**Technologies:** HTML, JavaScript, Tailwind CSS, Bootstrap, PHP, MySQL  
🔗 [GitHub repository](https://github.com/WellingtonNery/Owners)  
🌐 [View website](https://wellingtonnery.github.io/Owners)
